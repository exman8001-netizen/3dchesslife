# Local background music

Place licensed `.mp3`, `.ogg`, `.wav`, `.m4a`, or `.aac` tracks in this folder.
The app uses the track whose name contains `Brass Sabers` for the main-menu
intro and cycles through all available tracks during standard gameplay.
Freezone shared-room music takes priority while a Freezone game is active.

Browsers may require a click or key press before they allow audio playback.
